# 配体特征对比：PoC vs PLC

## 概述

PoC和PLC在配体原子特征维度上存在显著差异：
- **PoC**: 64维（19维基础特征 + 45维全局标签）
- **PLC**: 35维（30维原子特征 + 5维物理化学特征）

---

## 详细特征组成对比

### PoC (64维)

**来源**: `ppmol.get_atom_features_extended(mol, global_tag_dim=45)`

#### 组成结构
```
基础原子特征 (19维)
+ 全局分子标签 (45维)
= 总计 64维
```

**基础原子特征 (19维)** - 推测组成：
- 原子类型 one-hot (~11维)
- 杂化类型 (~6维)
- 其他原子属性 (~2维：芳香性、电荷等)

**全局分子标签 (45维)**：
- 将分子级别的全局特征复制到每个原子
- 可能包含：分子量、LogP、TPSA、氢键供体/受体数等
- 作为"标签"附加到每个原子特征上

**优点**：
- ✅ 每个原子都携带完整的分子上下文信息
- ✅ 便于模型学习分子级别的性质

**缺点**：
- ❌ 特征冗余（每个原子都重复相同的45维全局信息）
- ❌ 参数量更大（输入维度64 vs 35）
- ❌ 可能导致过拟合（全局信息可能淹没局部原子特征）

---

### PLC (35维)

**来源**: `PLK/preparation/ligand_features.py:extract_ligand_atom_features()`

#### 组成结构
```
原子身份特征 (11维)
+ 杂化类型 (6维)
+ 芳香性 (1维)
+ 环特征 (7维)
+ 度特征 (5维)
+ 电子效应 (3维)
+ 构象柔性 (2维)
= 总计 35维
```

#### 详细分解

**1. 原子身份特征 (11维)** - One-hot编码
```python
ATOM_TYPES = ['C', 'N', 'O', 'S', 'F', 'P', 'Cl', 'Br', 'I', 'H', 'Other']
```
- 碳 (C)
- 氮 (N)
- 氧 (O)
- 硫 (S)
- 氟 (F)
- 磷 (P)
- 氯 (Cl)
- 溴 (Br)
- 碘 (I)
- 氢 (H)
- 其他 (Other)

**2. 杂化类型 (6维)** - One-hot编码
```python
HYBRIDIZATION_TYPES = [SP, SP2, SP3, SP3D, SP3D2, UNSPECIFIED]
```
- SP: 线性（如炔烃）
- SP2: 平面三角形（如烯烃、芳香环）
- SP3: 四面体（如烷烃）
- SP3D: 三角双锥
- SP3D2: 八面体
- UNSPECIFIED: 未指定

**3. 芳香性 (1维)** - 二值特征
```python
[float(atom.GetIsAromatic())]
```
- 0: 非芳香性
- 1: 芳香性

**4. 环特征 (7维)**
```python
- 是否在环中 (1维)
- 在3元环中 (1维)
- 在4元环中 (1维)
- 在5元环中 (1维)
- 在6元环中 (1维)
- 在7元环中 (1维)
- 在8元环中 (1维)
```

**5. 度特征 (5维)** - 归一化连续值
```python
- 总度数 / 6.0
- 显式价 / 6.0
- 总价 / 6.0
- (形式电荷 + 2) / 4.0  # 归一化[-2,2]到[0,1]
- 自由基电子数 / 2.0
```

**6. 电子效应特征 (3维)** - 连续值
```python
- Gasteiger部分电荷 (1维)
- Crippen LogP贡献 (1维)
- TPSA贡献 (1维)
```

**Gasteiger电荷**：
- 模拟静电相互作用
- 基于电负性和拓扑结构计算
- 范围通常在 [-1, +1]

**Crippen LogP贡献**：
- 原子级疏水性
- 预测分配系数的贡献
- 正值=疏水，负值=亲水

**TPSA贡献**：
- 拓扑极性表面积贡献
- 预测膜通透性
- 与氢键形成能力相关

**7. 构象柔性特征 (2维)** - 连续值 + 二值
```python
- RMSF (Root Mean Square Fluctuation) (1维)
- 柔性标志 (1维): RMSF > 1.0Å 则为1，否则为0
```

**RMSF计算方法**：
1. 生成50个低能构象（ETKDGv3算法）
2. MMFF94力场优化
3. 对齐所有构象
4. 计算每个原子位置的标准差

**生物学意义**：
- 柔性区域更容易适应蛋白结合口袋
- 刚性区域提供结合特异性
- 熵效应：柔性损失影响结合亲和力

## 关键差异分析

### 1. 全局 vs 局部特征

**PoC策略**：
```python
# 每个原子携带完整分子信息
atom_features = [local_features (19D), global_tag (45D)]
```

**优点**：
- 模型可以直接访问分子级别信息
- 适合需要全局上下文的任务

**缺点**：
- 特征冗余严重
- 可能掩盖局部原子差异

**PLC策略**：
```python
# 仅使用原子局部特征
atom_features = [local_features (35D)]
# 全局信息通过GNN聚合获得
```

**优点**：
- 特征紧凑，无冗余
- 强制模型通过GNN学习全局信息
- 更符合消息传递范式

**缺点**：
- 需要足够深的GNN层来聚合全局信息

---

### 2. 电子效应建模

**PoC**: 可能包含在全局标签中，但不是per-atom的

**PLC**: 显式的per-atom电子效应特征
- **Gasteiger电荷**: 静电相互作用
- **LogP贡献**: 疏水性
- **TPSA贡献**: 极性表面积

**生物学意义**：
- 蛋白-配体结合主要由静电和疏水作用驱动
- Per-atom的电子特征更精确地描述这些相互作用
- 对于结合位点预测至关重要

---

### 3. 构象柔性分析

**PoC**: 无构象柔性特征

**PLC**: 基于多构象系综的RMSF分析

**计算流程**：
```
1. 生成50个低能构象 (ETKDGv3)
   ↓
2. MMFF94力场优化
   ↓
3. 对齐所有构象
   ↓
4. 计算每个原子的RMSF
   ↓
5. 标记柔性原子 (RMSF > 1.0Å)
```

**生物学意义**：
- **诱导契合 (Induced Fit)**: 柔性配体可以调整构象以适应蛋白口袋
- **熵效应**: 柔性损失影响结合自由能
- **药物设计**: 刚性分子通常有更好的选择性

**示例**：
```
刚性核心 (RMSF < 0.5Å):
  - 芳香环系统
  - 提供结合特异性

柔性侧链 (RMSF > 1.5Å):
  - 旋转键
  - 适应口袋形状
```

---

### 4. 环特征细化

**PoC**: 简单的"是否在环中"标志

**PLC**: 详细的环大小分析（3-8元环）

**药物化学意义**：
- **5元环**: 呋喃、吡咯（常见杂环）
- **6元环**: 苯环、吡啶（最常见）
- **7元环**: 较少见，通常更柔性
- **3-4元环**: 张力环，反应活性高

## 性能对比（理论分析）

### PoC (64维) 的优势

1. **即时全局信息访问**
   - 每个原子都知道分子的整体性质
   - 适合需要快速全局判断的任务

2. **更少的GNN层需求**
   - 不需要通过多层消息传递来聚合全局信息

### PLC (35维) 的优势

1. **更精确的局部建模**
   - Per-atom电子效应（Gasteiger、LogP、TPSA）
   - 构象柔性分析（RMSF）
   - 详细的环特征

2. **更好的泛化能力**
   - 无特征冗余
   - 强制模型学习原子间关系
   - 符合图神经网络的归纳偏置

3. **计算效率**
   - 更少的参数
   - 更快的前向传播

4. **生物学相关性**
   - 电子效应直接对应物理相互作用
   - 柔性特征对应诱导契合机制
   - 更适合结合位点预测任务

---

## 推荐使用场景

### 使用PoC (64维) 如果：

- ✅ 任务需要强全局上下文（如分子性质预测）
- ✅ 数据集较小，需要更多先验信息
- ✅ 计算资源充足

### 使用PLC (35维) 如果：

- ✅ 任务是局部的（如结合位点预测）
- ✅ 需要精确建模原子级相互作用
- ✅ 希望模型学习原子间关系而非依赖全局标签
- ✅ 需要更好的泛化能力
- ✅ 计算资源有限

## 总结

### 关键改进（PoC → PLC）

1. **特征紧凑化**: 64D → 35D（减少45%）
2. **电子效应建模**: 新增per-atom Gasteiger、LogP、TPSA
3. **构象柔性分析**: 新增RMSF和柔性标志
4. **环特征细化**: 简单标志 → 详细环大小分析
5. **去除冗余**: 移除45维全局标签

### 设计哲学转变

**PoC**: 全局信息 + 局部特征
- 每个原子携带完整分子上下文
- 适合快速原型验证

**PLC**: 纯局部特征 + GNN聚合
- 强制模型学习原子间关系
- 更符合图神经网络范式
- 更适合结合位点预测任务

### 推荐

对于**蛋白-配体结合位点预测**任务，**PLC的35维特征更优**：
- ✅ 精确的per-atom电子效应建模
- ✅ 构象柔性分析（诱导契合）
- ✅ 无特征冗余，更好的泛化
- ✅ 更少的参数，更快的训练
