# PLC vs PoC 距离计算对比分析报告

## 📊 执行摘要

对比了 PLC（使用 coords_original）和 PoC（旧方法）的距离计算结果，分析了20个随机样本，共计9,364个残基。

### 关键发现

1. **✅ 高度相关**：平均相关系数 = 0.9985
2. **⚠️  系统性差异**：PLC距离普遍比PoC大约 0.42 Å
3. **📉 结合位点识别差异**：PLC识别的结合位点残基更少（更严格）

## 6. 差异原因分析

### 6.1 可能的原因

1. **配体坐标差异** ⭐⭐⭐⭐⭐
   - PLC使用 `coords_original`（原始实验坐标）
   - PoC可能使用了经过优化或处理的坐标
   - 系统性偏移0.42 Å符合这个假设

2. **氢原子处理** ⭐⭐
   - 虽然都使用重原子，但添加氢原子的方式可能不同
   - 可能影响重原子坐标的微小调整

3. **距离计算方法** ⭐
   - 两者都使用全重原子计算
   - 方法应该相同，不太可能是主要原因

4. **坐标精度** ⭐
   - PDB文件精度通常为0.001 Å
   - 0.42 Å的差异远大于精度误差

### 6.2 验证假设

## 7. 影响评估

### 7.1 对模型训练的影响

#### 正面影响 ✅
1. **更准确的距离**：PLC使用原始实验坐标，更接近真实结构
2. **更严格的结合位点定义**：减少假阳性
3. **一致性更好**：所有复合物使用相同的坐标处理流程

#### 潜在影响 ⚠️
1. **标签变化**：约7.4%的残基距离差异 ≥ 1.0 Å
2. **结合位点残基数减少**：平均减少1-5个残基
3. **模型需要重新训练**：使用新的距离标签

### 7.2 对结合位点预测的影响

假设使用5Å阈值定义结合位点：

```
平均影响:
  - 每个复合物减少 1-2 个结合位点残基
```

## 8. 建议和结论

### 8.1 主要结论

1. **✅ PLC和PoC距离高度相关**（r = 0.9985）
   - 两种方法的距离排序基本一致
   - 主要差异是系统性偏移（+0.42 Å）

2. **⚠️  PLC距离系统性偏大**
   - 平均差异：0.42 Å
   - 92.6% 的残基差异 < 1.0 Å
   - 7.4% 的残基差异 ≥ 1.0 Å

3. **⚠️  结合位点识别有差异**
   - PLC识别的结合位点残基更少（更严格）
   - 5Å阈值：平均少1-2个残基
